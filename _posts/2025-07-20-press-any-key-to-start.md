This project was my first independent game jam which I made over the summer following my first year in university. 

I wanted to take a unique spin on whatever the theme of the game jam, so after the theme was revealed, which ended up being in the evening due to different time-zones, I got to work brainstorming.
The theme ended up being 'Just get started', which threw me through a loop since I was expecting a theme I could take in an abstract direction, whereas this theme was rather straight forward. 
Despite this, I ended up making a game revolving around the keys of a keyboard being physical tiles the player could interact with which made for some interesting puzzle layouts.

Since I wanted this project to be a demonstration of my ability to learn under pressure. I used Godot Engine for this project, an engine and programming language I had zero experience in beforehand. Thankfully, I was able to adapt in time and create the project I am currently most proud of, and give myself a headstart when learning Unity in a later module of university, since both engines use written code rather than visual coding like Unreal Engine and both engines have a similar layout.
